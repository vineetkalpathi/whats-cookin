# Amma's recipes: Asian Cabbage Salad

A blog-style chopped slaw written as commentary on each component, with no measurements. **The captured page is an excerpt: the dressing recipe is missing.**

One of the `ammas-recipes` PDFs. The PDF has no extractable text layer; the transcription in the
raw file was made from page renders at ingest.

## Key takeaways
- A build-by-feel slaw: the page comments on each component rather than measuring it.
- **Hand-slicing whole cabbage heads is the point**; bagged slaw is a grudging fallback.
- Colour is a design goal — green and red cabbage, orange carrot, red pepper, green edamame, cilantro.
- Edamame carries the protein and lets the salad stand on its own.
- Nuts are toasted first and added last, and toasting demands constant attention.
- Dressing is added incrementally to taste, never all at once.
